# 3xG.dnGrep.Theme
A Dark-oled theme for dnGREP

 3xG - Gold, Green & Gr(e|a)y - Is a Dark-oled theme for [dnGREP](https://github.com/dnGrep/dnGrep) created with [@doug24's ThemeEditor](https://github.com/doug24/ThemeEditor)

v1 02-12-2025

features darker backgounds, gray edit boxes with warm bright gold & green highlights with only a few contrasting blue accents.

off white\warm text (easy on the eyes with less blue light)

old sckool gradient buttons! (easy to find and click)
